# Decisions

- Deterministic collection happens before AI synthesis.
- `OBSERVED`, `INTERPRETATION`, and `WATCH` remain separate.
- Cuttingboard is optional, read-only context and never writable authority.
- PRE-MARKET is the first shipping cadence.
- Local and simple comes before services or frameworks.
- Signal over plumbing: the brief carries conclusions and useful tables; collapsed ledgers carry proof.
- A commissioning run names the market phase it actually collected in (resolved from the exchange clock), never a hardcoded checkpoint.
- Same-day post-close runs may use daily history through the prior completed session while the provider has not published today's bar; that lag is visible in coverage, never fills TODAY, and never applies beyond that day.
- Only LIVE runs publish; fictional replay output never reaches the public brief.
- The synthesis contract asks for one short headline claim, one global coverage caveat, and no table restatement; the validator enforces the headline bound and fail-closed grounding unchanged.
- The model receives the bounded synthesis projection (one copy of each admitted fact, legend, leadership IDs, attention, compact sources, coverage, schema); the full normalized record stays local and `--full-packet` reproduces the original payload for diagnostics.
- Deterministic code owns every persistent continuity identity (watch, relationship, comparison, snapshot ref); the analyst proposes new items and assessments and never names or renames a carried record.
- Saved artifacts separate deterministic observed/comparable change (`observed`) from model-authored assessment (`assessment`, class INTERPRETATION); the point-in-time factual record stays usable without the interpretation.
- Premarket admits only the previous exchange session's accepted close handoff; intraday editions admit this session's premarket anchor and latest accepted edition. Anything else is an explicit cold start.
- A post-close run may admit labeled PROVISIONAL session-ending prints (final fifteen minutes before the close, within ninety minutes after it) so a cron-delayed close can still hand off; the handoff and its closing character are marked provisional. Without any session observation the run records EARLIER_HISTORY_ONLY and does not advance the close handoff; the next morning says close continuity is unavailable.
- GitHub Actions artifacts are short-horizon operational continuity (thirty days), not historical storage; artifact contracts are versioned and hashed so a permitted archive can adopt them later.
- Restore takes the newest unexpired continuity artifact of a main-branch `schedule.yml` run that concluded `success` or `failure`. Its upload runs only when every earlier step, the pipeline among them, succeeded, and precedes the push and the Pages deployment, so the artifact proves acceptance and a push or Pages failure no longer rolls accepted state back (R1). A rejected synthesis uploads nothing; a cancelled or unfinished run is not eligible.
- One configured analyst for every edition; identity, route, budget profile, and usage are recorded per run. No provider registry.
- The configured analyst carries one bounded fallback (`fallback_model`, Fable 5). A synthesis checkpoint attempts the primary and, only when OpenRouter reports it has no eligible endpoint (the explicit "no endpoints found" 404, a routing failure before any billing), makes exactly one fallback call; a bare or unrelated 404, transient, auth, malformed, and local-grounding failures never fall back, an environment override carries no fallback, and each run records the primary failure (sanitized, never the raw provider body), whether fallback occurred, and the model that served. OpenRouter's own `models` array is deliberately not used: a "no endpoints" 404 halts that chain rather than advancing it, and it would hide the primary failure and could bill twice.
- The configured primary analyst is Opus 5.5 (`anthropic/claude-opus-5.5`, owner ruling 2026-09-27) for both daily syntheses. The bounded fallback (Fable 5), the Anthropic-only provider pin, the rich and light profiles and budgets, the prompt, the narrative schema and the recorded provenance are unchanged, and a trading day still makes exactly two analyst calls. A workflow experiment runs the checkpoint it was dispatched with (`-f checkpoint=… -f experiment=true`); only a commissioning experiment resolves the market phase from the clock.
- Light editions receive a deterministically selected context and can cite only what they were shown; nothing is truncated to fit a budget.
- Rich interpretation is scarce: the premarket edition and the opening-structure update (open +30 minutes) are the day's only analyst calls. Open +1M, the hourly refreshes and the close are deterministic: they refresh the observed record under the last accepted interpretation, frozen as a hashed continuity record, and never rewrite it. The standalone rich CLOSE_1M edition is removed rather than fitted to a larger budget.
- Checkpoints are anchored to the exchange session, never to a Pacific wall clock: premarket at open −30 minutes, open +1 and +30 minutes, hourly refreshes at exchange-clock hours, the close at close +1 minute. The exchange calendar is the only authority; times are displayed in Pacific time and therefore move with New York's seasons (the opening-structure update reads 7:00 AM PT in New York daylight time and 8:00 AM PT in standard time now that British Columbia keeps UTC−7).
- A synthesis checkpoint is due only within its own short window (`schedule.TOLERANCE_MINUTES`, twenty minutes) so the wake that naturally follows it is its one attempt; the :31 UTC wake that exists for the other New York season lands thirty-one minutes late and resolves to SKIP, never a second paid attempt, whatever the first attempt's outcome. Deterministic refreshes and the close keep the forty-five-minute window.
- A watch's criteria keep the values their author saw: the rows a criterion quotes are frozen with the watch when it is created and travel with it; a later synthesis may reassess or replace the watch, a deterministic refresh may not, and newer market data never changes a carried threshold.
- The close snapshot hands the session off from deterministic state: closing snapshots from its own evidence, the carried assessment labeled with the checkpoint that interpreted it. A close without a same-session interpretation still hands off (no page); a close or refresh without observations from the session publishes nothing and leaves the last accepted page and bundle untouched.
- Every page states three clocks, each saying what it measures: **Prices**, the latest current equity print across the page's tables (else `prior close <date>`); **Analysis**, when the interpretation it shows was made and by which synthesis edition (`premarket`, `opening structure`); **Next**, the scheduler's next checkpoint in reader words (`price refresh`, `analysis update`, `close snapshot`, or the next session's `premarket analysis`). A synthesis whose prices and analysis read the same PT minute shows one `Prices & analysis` line. Prices is the visual anchor; the run's collection time stays in Technical details. The masthead carries the date; LIVE renders no status word, while SAMPLE, LIVE COMMISSIONING and LAST GOOD BRIEF stay loud with the edition named once. A carried page's "What changed" caption ends at its analysis ("… · through the 7:01 AM PT analysis"). Each row keeps its own observation clock or date; frozen prose cites the rows the analyst saw at their own clock, tables cite this run's rows.
- A page never claims freshness it no longer has: the Next line carries the next checkpoint's absolute time and its own PT words, and the page's inline script rewrites it to "Update due … has not published" once that time plus a fifteen-minute grace (`render.OVERDUE_GRACE`) has passed, on load, on becoming visible and every minute. The wording is neutral because the cause may be a failure or a legitimate no-publish. There is no server-side state, status value or network call, and without JavaScript the page is unchanged.
- Rates are Treasury's official daily par curve: fitted from indicative quotes near 3:30 PM ET and published once a business day, so every page shows the previous business day's curve and no intraday yield exists anywhere in the pipeline. The rates module leads Macro & rates with a dated caption ("U.S. Treasury par curve · Thu, Sep 24 · official daily observation", never "close", never a clock time), the four tenors 2Y/5Y/10Y/30Y, the 2s10s and 5s30s spread lines, the named curve move, an inline chart of the observed tenors with the prior entry dashed, and notes; the analyst's paragraphs follow as the why. Freshness is judged against weekdays, not NYSE sessions, because the bond market keeps holidays the NYSE trades through: a curve older than the previous weekday but at most five calendar days old reads "latest official daily observation"; older than that it is stale and shows its levels, date and a quiet note only. The analyst frames the backdrop with it and never presents it as the cause of, reaction to or explanation for current-session prints; when the curve predates a release, the module and the analyst say so.
- The curve move is named by a pure deterministic classifier (`curve.py`, rule version `curve-move.v1`), never by the analyst: an ordered rule table over the integer 2Y and 10Y changes (twist, bear/bull steepener or flattener, slight steepening or flattening, parallel shift, little changed), with the 5s30s change able to make it a mixed move or add a long-end note. Its threshold is the configured bp SMALL magnitude (`config/magnitude.json`), read, never copied. The result is a typed, non-citable packet record (`packet["curve"]`) saved with the evidence and shown to the analyst read-only; the analyst names the move only with its label and cites the tenor and spread rows.
- Spreads are signed long minus short in whole basis points (`treasury-2s10s`, `treasury-5s30s` and their changes, derived from one entry's legs with `input_ids` and a formula version). Steepening means the signed spread rose, whatever the level's sign, so on an inverted curve steeper means less inverted; a spread level is a level (no plus sign, a minus only when inverted). Reader copy never says "today", "wider" or "narrower". `2s10s` and `5s30s` are bounded labels in analyst prose, exactly those forms.
- Rates are never coloured: yield and spread levels and their changes render in neutral ink, as `5.18%` and whole `bp`, everywhere they appear (tables, module, proof lines, ledger, prose placeholders). The sign carries direction and the curve move label carries meaning; rising yields are neither good nor bad.
- The metals table is captioned "Metals" inside Macro & rates, its caption led by its spread label and carrying its own clock (equity prints are current while the curve is prior-day; the prompt forbids tying one to the other); "Cross-asset structure" named more than the table holds, and a section of its own left the biggest cross-asset moves orphaned below the sectors (2026-09-28: GLD −3.21% and GDX −3.77% at the open, five screens down with no prose slot). The one macro paragraph may speak to gold and miners when they move the story; no Metals prose slot is added to the schema.
- A current print's reader label is presentation, read from that row's own `observed_at` against the session's open and close: "Premarket", "Intraday" or "After-hours vs prior close", "Near-close vs prior close" for a PROVISIONAL print, and "Latest trade vs prior close" when the phase cannot be placed in this session or a table's prints span phases. One helper (`render.current_print_label`) supplies it to every path (markers, table proofs and captions, ledger). A frozen row keeps the phase it was observed in; nothing is labeled as the official close. The metric string (`premarket return`), evidence ID, identity key and comparisons are unchanged.
- Current availability is owned by this run's deterministic packet and source state: missing domains, coverage limitations, the Sources drawer and the evidence rows. The analyst's `banner.limitation` is point-in-time interpretation; it renders, with its marker, only on the synthesis edition that wrote it and is withheld, never edited, on carried editions.
- Reader surfaces use reader words; internal contract vocabulary (metric strings, statuses, checkpoint names, source reasons) stays valid in Technical details and the saved artifacts. The coverage list says `not collected` where the packet says `not automated`, and names market sections an edition could not fill as "Not in this edition"; optional Cuttingboard absence is not an editorial omission, and Technical details state its status and reason. A carried watch reads "From an earlier read". A paragraph's uncertainty and alternative explanation render as separate "Caveat:" and "Could also be:" lines, never one unlabeled sentence.
- Visible absence vocabulary is three terms: `no print` (current observation missing, history present), `—` (structurally not applicable), `not collected` (source not automated). A displayed value that rounds to zero is an unsigned neutral zero.
- The analyst selects attention triggers through one surface only: `attention[]`, each item an admitted deterministic trigger `id` with a `why`; deterministic code derives the selected IDs from those items for the frozen interpretation, and unknown or repeated IDs fail closed. The former `attention_ids` list was a second model-owned copy of the same decision that the provider's strict grammar could not tie to `attention[]`; production run 35347858192 (PREMARKET, 2026-09-18) returned three IDs and an empty list, schema-valid on the wire and impossible locally, so the duplicate authority was removed rather than the equality check loosened.
- The narrative contract is `market-brief.narrative.v2`: v1 plus a required `take` after `summary` (`text` with a 160-character editorial target, class INTERPRETATION, up to four evidence IDs). The take is the single most useful interpretation in the brief that its analyst could turn out to be wrong about: one short sentence, not a prediction and not trade advice. It is empty (no text, no evidence) when the evidence is too thin, and text without evidence or evidence without text fails closed. It rules an alternative out only when supplied evidence shows the alternative false: missing data (news, breadth, anything not collected) rules nothing out. It is a current-condition record like the headline and the read: supplied current evidence only (no prior `anchor:` refs, no `cmp-` comparison IDs), grounded numeric placeholders, no literal numbers, the SAMPLE current-language rule, and the trade-language rule with one narrow exemption for the market noun "sell-off" ("sell-offs", "selloff"); "buy", "sell" as an action, entries, targets, sizing, execution and orders still reject. The rows it cites freeze with the interpretation, so a carried take shows the values and clocks its analyst saw while the tables show this run's. It renders as one "The take:" line after the read on synthesis and carried pages, with the existing evidence marker and no new styling, and renders nothing when empty. Continuity changes only in which rows freeze: no take in edition state, carried state or the close handoff, and no continuity or bundle schema change; an interpretation frozen under v1 still renders on the same session's refreshes.
- Voice is a positive prompt contract (synthesis v0.3): a sharp desk colleague writing to one discretionary trader building macro intuition, claim first, one idea per sentence, exact figures only through evidence placeholders and only when they sharpen the point, a mechanism only when the evidence supports one, the important blind spot stated once. Prompt provenance stays the prompt hash; there is no prompt-version field. Each synthesis edition records advisory voice telemetry in `metadata.style` (counts of eight contract words in reader prose, numeric placeholders, whether the take is present, its length, and whether it repeats the headline). It is observation only: it never affects acceptance, publication, a retry or the call count, which stays two analyst calls a day.
- The analyst reads its output contract in the same factored `$defs`/`$ref` form that `response_format` enforces (owner ruling 2026-09-25, reversing the PR #30 choice to keep the user-message copy inlined). The inlined copy cost 3,191 bytes per request, and with the take it put the real 2026-09-24 opening-structure context 26 bytes over the 40,000-byte light budget. The factored copy expands exactly to the inlined transport contract, so no field, bound description, enum, requirement or validation rule changes; the budgets and the light projection are unchanged. The isolated Claude CLI route still enforces the inlined form through `--json-schema`.
- The provider-enforced schema stays inside the envelope Anthropic has compiled fresh and accepted (5,295 bytes, 72 nodes, 11 objects, 55 properties; 2026-09-18). The first live check of the take (2026-09-25, 5,497 bytes, 75 nodes, 12 objects, 58 properties) was rejected with HTTP 400 before generation; every other request difference was ruled out and an open-source grammar compiler ranks all four schemas ever sent in the order Anthropic accepted and rejected them. The fix is transport-only: each paragraph array states its items' text bound once ("Each text: At most N characters"), so the summary and section paragraphs compile as one rule; every bound is still described and enforced locally. Every OpenRouter HTTP error recorded with its body (all but authentication failures, including a no-endpoint primary failure kept in provenance) now includes the provider's own bounded, printable error message from OpenRouter's `metadata.raw`, and nothing else of the provider body.
- One idea has one home (editorial compression pass, owner rulings D1–D4 of 2026-09-27 and M1–M9 of 2026-09-28). The lead claims it: the headline names the condition, `character` the latest tape, the summary the most important supported mechanism now (never the headline again, never prior-session context when current evidence carries a stronger read), the take the stance carried forward and what would show it wrong. One evidence section proves it and one watch tests it. The prompt states these roles; nothing deterministic enforces wording, so they are judged from pages.
- The headline figure strip is retired and not replaced. Its composition and clocks changed by time of day, and on 2026-09-28's opening page it put Friday's QQQ daily return (no current print) at equal weight beside Monday's live SPY and XLY prints under a headline saying weakness was spreading. The tables and their captions are the current-print surfaces; a scoreboard returns only if live use proves something is missing.
- The banner label (RISK-ON / RISK-OFF / MIXED / INDETERMINATE) is recorded in every continuity record and never displayed. It was MIXED on every page of the first live week but one, the headline already carries the flip when it happens, and a single word mislabels a tape with NVDA +2.99% and energy +0.86% as RISK-OFF. Market Memory may read it as a series.
- What changed is adjudication, once. Verdicts on carried watches (strengthened, weakened, reversed) render first, then verdicts on carried relationships, then analyst-interpreted changes. A lower-priority record whose cited current evidence adds nothing a higher-priority bullet already cited is the same conclusion from the same measurements and is not shown; a record that cites evidence of its own stays. "Unresolved" is not a change and never renders there; the assessment is still appended to the record. Every watch verdict lives here, including one on a watch that stays live (owner ruling D1, M2). The prompt asks the analyst not to write the same move as a change, a relationship and a watch update, and never to propose a relationship and a watch on one claim; the renderer's rule is the backstop.
- What matters next shows exactly the watches continuity will carry forward: new watches first, then still-active carried watches not reversed, at most `CARRY_LIMIT`, the same selection `continuity.edition_state` makes, so the page never invents a ranking. A live carried watch shows its question, its horizon and its confirm / changes-it criteria, at the values its author saw, never its verdict. The frozen interpretation record keeps each carried watch's `confirmation` and `contradiction` beside its question (F2, 2026-09-29): an additive change under the unchanged `market-brief.continuity.v1` schema, with no new state, identity or lifecycle, and no change to the analyst context, which already read them from the carried state. An interpretation frozen before then still loads, is admitted and renders its carried watches as questions alone; nothing migrates it. Rendered criteria count toward a flag's coverage exactly as a new watch's do. Every other carried watch, expired or set aside without a verdict, reassessed or not, is one collapsed "Earlier watches · N ended without a verdict" drawer rendered from the frozen prior state: audit, not attention, and no new state. A watch whose horizon passes during a deterministic refresh keeps its place and its "horizon passed" note (owner ruling D3: the refresh invariant is not loosened).
- A flag (attention item) renders only when its instrument is not already in the lead, the rendered What changed or a live watch, by cited row or by name; the frozen selection is unchanged and empty is normal. The prompt asks the analyst to select only uncovered triggers.
- Sections run Macro & rates (with Metals) → Sector view → Equity structure: the backdrop, then breadth, then the names, matching the top-down lens the product exists to teach. The order is fixed; it is not chosen per day.
- One number style everywhere: `+0.53%`, `−5.30 pp`, `−6 bp`, `90.02 USD` — no space before a percent sign, a true minus for every negative, a space before a unit word. Placeholders, tables, proofs and the ledger agree. On phones numeric cells never wrap, tables use automatic layout below 600 px, sublines keep label and value together, and a headless-Chrome probe checks no numeric text spills past its cell at 390, 360 and 320 px.
- The analyst prompt's byte ceiling is 11,000 (owner ruling D2): a ceiling, not a target, raised once for the role-separation and deduplication rules (+829 bytes) and not raised again to keep redundant editorial prose. Watch criteria must be observable by the horizon (from premarket, NEXT_BRIEF is the opening-structure update thirty minutes after the open): 2026-09-28's premarket wrote a close test on a 7:00 AM horizon, it expired at the checkpoint meant to test it, and nobody saw a verdict.
- Presentation changes are verified offline: re-rendering saved production artifacts (evidence, context, narrative) under the new renderer, fixtures and replay, screenshots and the phone-width harness. A prompt change is judged from the next normal day's scheduled PREMARKET and OPEN_30M; no paid synthesis is run to inspect wording, and any additional paid call needs explicit owner approval (owner ruling M9).
- Tests run on every pull request and on every push to `main` except one whose whole diff is `publish/index.html`. That page is the scheduler's entire publication write surface (its publish step stages nothing else, and a test pins the ignore list to exactly what it stages), so a source, test, template, prompt, config or workflow change reaching `main` by any route is tested. The scheduler pushes with the workflow token, which starts no workflow run, so the ignore is a second guard and there is no CI or publish recursion. Branch protection, scheduler authority and workflow permissions are unchanged.
